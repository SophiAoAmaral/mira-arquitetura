📖 Sobre o projeto

Mira é uma landing page institucional para um estúdio de arquitetura residencial autoral. O projeto explora uma estética sofisticada e silenciosa — tipografia elegante, paleta sóbria e fotografia em destaque — para comunicar a proposta de "casas que habitam o tempo".
A página apresenta o escritório, portfólio de obras recentes, serviços oferecidos, depoimentos de clientes e um formulário de contato para agendamento de visitas.

"Uma casa não deveria parecer estar no lugar — deveria sempre ter estado."
— Helena Mira, arquiteta titular

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
✨ Funcionalidades

🎬 Animações on scroll — elementos com a classe .hidden aparecem suavemente conforme o usuário rola a página (via Intersection Observer).

🎠 Carrossel infinito de prêmios — listagem horizontal com rolagem contínua exibindo premiações e reconhecimentos.

🖼️ Galeria de portfólio — grid de projetos residenciais recentes (2021–2025) com cidade e categoria.

💬 Seção de depoimentos — relatos de clientes em formato editorial.

📝 Formulário de contato com validação — validação client-side dos campos (nome, e-mail, telefone, tipo de projeto e mensagem) com mensagens de erro inline.

🧭 Navegação suave — âncoras internas para Sobre, Portfólio, Serviços, Clientes e Contato.

📱 Layout responsivo — adaptação para desktop, tablet e mobile.(em execução)

🚀 Como executar localmente

Opção 1 — Abrir diretamente no navegador
bashgit clone https://github.com/SophiAoAmaral/mira-arquitetura.git
cd mira-arquitetura
Depois é só abrir o arquivo index.html no navegador.

Opção 2 — Usando Live Server (recomendado no VS Code)

Instale a extensão Live Server no VS Code.
Abra a pasta do projeto.
Clique com o botão direito em index.html → Open with Live Server.
